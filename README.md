# Alimentação do Bebê

Guia de introdução alimentar até 1 ano de vida – Dra Luiza Menel CRMSC 30435.

Site estático (HTML, CSS e JavaScript, sem dependências), publicado pelo GitHub Pages em https://draluizamenel.online.

## Estrutura

- `index.html` — página do guia
- `css/estilo.css` — visual (paleta, cartões, janela de detalhe)
- `js/app.js` — abre o detalhe dos elementos clicáveis
- `img/fotos/` — fotos das seções e da manobra de desengasgo
- `img/ilustracoes/` — ícones em SVG

## Ver no computador

Abra `index.html` no navegador ou rode, nesta pasta:

```
python -m http.server 8731
```

e acesse http://localhost:8731.
